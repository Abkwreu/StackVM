# StackVM
## Features
* Low-level, assembly-like programming language
* Fluent Python program building API
* Program visualization UI powered by Flet

## Getting started
* See `examples/examples.py` for example programs
* See the documentation for the `StackMachine` class for information on all of the opcodes
